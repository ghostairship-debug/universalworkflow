# M36 Phase 1: Conversational Workbench Flow

Status: completed
Opened: 2026-04-24
Closed: 2026-04-24
Baseline: accepted `M36 Phase 0`

## Purpose

Turn the frozen `M36 Phase 0` workbench seams into a usable conversational workbench flow without collapsing the operator/workbench split.

## Scope

This phase includes:

- guided goal intake on `/ui/workbench`
- recent session visibility and session reload from the workbench
- coherent plan-draft, goal-packet, cluster, and execution-default projection
- active run checkpoint visibility from the workbench
- additive CLI/API parity for the richer interaction-session flow

This phase does not include:

- generated profiles
- automation watchdogs
- broader capability-ecosystem productization
- streaming chat or free-form conversational shells

## Outcome

`M36 Phase 1` is complete.

The workbench now exposes:

- richer goal intake with constraints, assumptions, artifact refs, and follow-up context
- recent session listing and session revisit
- execution-default projection from accepted `M35`
