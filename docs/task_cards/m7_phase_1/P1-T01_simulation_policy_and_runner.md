# P1-T01 - Simulation Policy And Runner

## Goal

Add the first simulation policy/report contracts plus a deterministic local simulation runner.

## Scope

- seed-backed simulation policy definitions
- one deterministic simulation report contract
- one local runner that evaluates run consistency/closure readiness

## Done When

- policies resolve by preset
- reports are deterministic
- reports explain whether simulation was disabled, skipped, passed, or failed
