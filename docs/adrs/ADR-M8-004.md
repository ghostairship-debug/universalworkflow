# ADR-M8-004 - TaskKind And Capability Projection Policy

## Status

Accepted

## Decision

`TaskKind` remains intentionally small and stable.

`M8` does **not** introduce new task-kind breadth for external tools. Tool diversity is expressed through:

- `CapabilitySource`
- `CapabilityRegistry`
- `ToolProjectionManifest`
- server profiles / trust tiers

## Rationale

The repository should avoid task-kind explosion and instead concentrate variability inside the capability plane.
