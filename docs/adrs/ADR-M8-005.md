# ADR-M8-005 - MCP Trust Model And Server Profiles

## Status

Accepted

## Decision

`M8` trust tiers are:

- `T0` built-in local capability
- `T1` local stdio MCP
- `T2` internal managed HTTP MCP
- `T3` third-party remote HTTP MCP

Approved default scope in `M8`:

- `T0`
- `T1`

All MCP integrations must use:

- allowlisted tools
- startup and call timeouts
- schema budget
- tool-count limit
- router-first projection instead of inventory-wide exposure

## Rationale

MCP defines transport and interaction shape, but not trust policy, least privilege, or token-budget discipline.
