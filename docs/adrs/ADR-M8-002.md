# ADR-M8-002 - Execution Lane Strategy

## Status

Accepted

## Decision

`M8` defines four execution lanes:

- `native_deterministic`
- `standard_agent`
- `durable_incremental`
- `graph_native_complex`

Lane policy:

- `feature_delivery` stays on `native_deterministic`
- `research_spike` is the first standard-agent pilot path
- `research_spike_reviewable` is the first durable pilot path
- graph-native execution is not the default and is reserved for explicit complex-state workflows

## Rationale

The repository needs a stable deterministic default while proving where borrowed agent/runtime substrate can replace custom infrastructure.
