# ADR-003: SQLite Local-First

## Context

M0 is a local-first bootstrap and must be reproducible on one machine without external services.

## Decision

Use SQLite as the only M0 persistence backend, with WAL mode enabled on connection and a repository layer keeping future PostgreSQL migration possible.

## Alternatives considered

- PostgreSQL from day one.
- In-memory persistence for bootstrap.

## Consequences

- Positive:
  Local initialization, reset, and smoke remain lightweight.
- Negative:
  Distributed semantics are intentionally postponed.
