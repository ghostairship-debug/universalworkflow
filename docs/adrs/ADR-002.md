# ADR-002: Evidence First

## Context

The project needs a machine-readable truth source for execution outcomes and later review decisions.

## Decision

`Evidence` is the machine truth record. `ReviewVerdict` stores only the review conclusion. If out-of-band change is detected in M0, the warning is appended to `Evidence.known_gaps` and review is not blocked.

## Alternatives considered

- Treat stdout and stderr as the canonical execution record.
- Put review conclusions directly inside the evidence blob.

## Consequences

- Positive:
  Human summary and machine-readable truth stay separate.
- Negative:
  M0 review remains intentionally minimal.
