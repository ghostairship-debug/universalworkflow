# ADR-M8-009 - Feature Flags And Promotion Rules

## Status

Accepted

## Decision

`M8` feature flags:

- `UAWO_ENABLE_AGENT_LANE`
- `UAWO_ENABLE_MCP_SOURCE`
- `UAWO_ENABLE_EXTERNAL_TRACE_EXPORT`
- `UAWO_ENABLE_DURABLE_PILOT`
- `UAWO_ENABLE_SKILL_EXPORT`

Promotion rules:

- fallback path must be tested
- public contract must not leak external runtime state
- operator projections must remain interpretable
- review/governance/budget semantics must not be weakened

## Rationale

Explicit flags and promotion rules let `M8` borrow infrastructure experimentally while preserving the repository's local-first baseline.
