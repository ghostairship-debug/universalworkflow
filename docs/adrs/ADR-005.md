# ADR-005: Conservative Concurrency

## Context

M0 has to preserve future claim semantics without pretending to implement safe concurrency.

## Decision

Use serial execution semantics in M0. Keep a claim check placeholder in dispatch. Enable SQLite WAL and reject a process-wide global mutex as the primary concurrency strategy.

## Alternatives considered

- Introduce a global mutex now.
- Implement full claim, lease, and barrier behavior in M0.

## Consequences

- Positive:
  The system stays simple while future protocol shape is preserved.
- Negative:
  Real concurrent execution is deferred to M2.
