# ADR-M8-007 - Observability Export Abstraction

## Status

Accepted

## Decision

`M8` adopts:

- OTel-first export abstraction
- sink-agnostic exporter interface
- Langfuse as the first implemented sink
- optional later LangSmith-compatible route

Local projections (`status-detail`, `inspection`, `summary`, `audit-report`) remain the canonical operator-facing interpretation layer.

## Rationale

The repository should externalize generic trace/eval substrate without surrendering its local governance and operator reporting model.
