# ADR-004: Runtime Anti-Corrosion Layer

## Context

LangGraph may be useful as a runtime substrate, but M0 must not let it leak into contracts or the core domain.

## Decision

Introduce `RuntimeGateway` as the only orchestrator-facing runtime interface. `packages/contracts/` and `packages/core_domain/` must not import `langgraph`. Runtime state stores only IDs, enums, and lightweight refs, never contract object instances.

## Alternatives considered

- Import LangGraph types directly into the service and contracts layer.
- Let runtime state persist complete contract objects.

## Consequences

- Positive:
  LangGraph stays replaceable and bounded.
- Negative:
  A small wrapper layer must be maintained even in the placeholder stage.
