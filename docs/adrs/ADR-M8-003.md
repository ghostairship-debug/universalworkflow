# ADR-M8-003 - Canonical IDs And State Mapping

## Status

Accepted

## Decision

The canonical product state remains repository/SQLite state.

Canonical and mapped IDs for `M8` include:

- `run_id`
- `review_id`
- `runtime_attempt_id`
- `simulation_id`
- `projection_id`
- `tool_call_id`
- `external_trace_id`
- `thread_id`
- `checkpoint_id`
- `assistant_id`
- `external_session_id`

Mapping rules:

- product truth stays in repository state
- external runtime refs are diagnostics-only
- external state never writes product transitions directly
- any lane promotion must support clearing external refs and degrading back to native execution

## Rationale

Borrowed runtimes and trace backends add useful refs, but they must not become the public business contract.
