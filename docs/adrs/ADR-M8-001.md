# ADR-M8-001 - Borrow / Wrap / Own Matrix

## Status

Accepted

## Decision

`M8` classifies external-ecosystem adoption into three layers:

- **Borrow**
  - standard agent loop (`create_agent + middleware`)
  - low-level persistence / checkpoints / threads / interrupts
  - generic trace/eval substrate
  - open skill-format semantics
- **Wrap**
  - `RuntimeGateway`
  - capability sources and projection
  - tool exposure policy
  - trace export abstraction
  - skill export/import adapters
  - repository-state to external-runtime-state mapping
- **Own**
  - run lifecycle
  - review/governance/budget/admission
  - domain packs, presets, workflow catalog
  - deterministic simulation
  - local-first fallback discipline
  - operator-facing projections and release gates

## Rationale

The repository should stop deepening generic substrate that official ecosystems already provide, but it must keep the product's control semantics and local-first governance model.
