# ADR-M8-008 - Durable Runtime Pilot Contract

## Status

Accepted

## Decision

The durable pilot in `M8` is:

- narrow in scope
- opt-in
- diagnostics-oriented
- mapped back into repository state

Pilot rules:

- initial run class: `research_spike_reviewable`
- external runtime refs appear only in diagnostics
- repository state remains canonical for run/review/budget/audit/governance
- kill criteria apply if durable integration requires public-contract leakage or weakens governance semantics

## Rationale

The goal is to validate borrowed durable substrate value without turning framework state into product truth.
