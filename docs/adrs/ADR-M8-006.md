# ADR-M8-006 - Fallback And Degradation Policy

## Status

Accepted

## Decision

All external `M8` capabilities are feature-flagged and disabled by default.

Degradation rules:

- agent-lane failure must allow return to native deterministic execution
- MCP failure must degrade to built-in capability only
- trace-export failure must not change run outcome
- durable-pilot disablement must return the repository to native/standard-agent lanes
- local operator projections remain authoritative even when external systems are enabled

## Rationale

`M8` is an integration cycle, not a rewrite cycle. Every borrowed path needs an immediate safe off-ramp.
